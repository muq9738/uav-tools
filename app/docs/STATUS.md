# App 状态

App 已直接接入唯一 native；默认与 CLI 一致为 meshopt，支持 raw、线程、内存预算、坐标覆盖和索引文件输入。当前使用 native 结构化进度及跨平台合作取消，不再统计正式输出目录估算进度。报告缺失或参数不符会失败。

完整模型在去除开发环境变量后，随包 App 与随包 CLI 生成的 5,425 个资产文件 SHA-256 完全一致，报告除耗时/RSS采样外一致；已观察到运行中进度推进和取消暂存清理。平台完成情况与未完成项在本文件维护，不在实现文档中复制容易过时的数字。

已有任务、队列、日志、SSE、历史持久化、目录锁及桌面目录选择；原生平台运行时由 `scripts/build.py` 收集，MyGo 与便携版共用 `resources/<平台>/`。没有另外一套 App 转换算法。

仍需完成目标 Windows 设备运行、macOS/Windows/Linux 桌面体验与低配测试，以及产品本身的性能验收。Go 外壳交叉编译不等于整个平台已经验收；新 CI 会在目标平台原生构建转换器并跑包内一致性检查，不能把尚未运行的 CI 配置写成通过结果。
